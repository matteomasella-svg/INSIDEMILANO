# 2EMME Digital Universe — Design System v1

## Obiettivo
Unificare l'impronta grafica delle piattaforme 2EMME, Hospitality e 3MATRIX senza uniformarne forzatamente funzione e densità.

## Principi non negoziabili
1. Photography-free by default: illustrazione vettoriale, line art, poster/travel-print 60s–70s.
2. Milano Collection come firma territoriale modulare.
3. Stessa geometria UI: griglia, card, navigazione, spacing, bordi, badge e stati.
4. Brand skins: 2EMME Corporate, 2EMME Hospitality, 3MATRIX.
5. Editorialità nel Guest/Inside; densità informativa nell'Host/3MATRIX.
6. Mobile first per Guest, Inside e Homebook; responsive desktop-first per Host e Mainframe.
7. Nessuna emoji; iconografia coerente e vettoriale.

## Componenti master
- App shell / sidebar / topbar
- Page heading + eyebrow
- Hero editoriale illustrato
- KPI card / metric card
- Action card / editorial card
- Badge / pill / status
- Data table
- Timeline / stepper
- Alert / notice
- Form controls
- Filter bar
- Bottom navigation mobile
- Empty/loading/error states
- Milano skyline signature
- Illustration frame

## Famiglie
### Host Control
Operativa, chiara, alta densità. Milano come firma e non come decorazione dominante.

### Guest Experience
Calda, editoriale, orientata al soggiorno. Accesso diretto a casa, servizi, pagamenti, supporto e Inside Milano.

### Inside Milano
Magazine/concierge illustrato. Nessuna fotografia standard. Milano Collection come linguaggio principale.

### Homebook / Manuali & Asset
Istruzioni visuali, progressive disclosure, quick guide, asset cards e supporto.

### 3MATRIX
Stessa struttura compositiva con skin intelligence. Quattro assi: Tempo, Performance, Consumi, Impact.
